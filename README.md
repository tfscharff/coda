# Coda

A music-focused project. Scope is still being defined.

## Versioning

Coda follows [Semantic Versioning](https://semver.org/). Releases are tagged `vMAJOR.MINOR.PATCH`
and recorded in [CHANGELOG.md](CHANGELOG.md). While the version is `0.x`, the API is unstable and
minor bumps may break things.

## Commits

Commits use [Conventional Commits](https://www.conventionalcommits.org/):

| Prefix | Meaning | Version bump |
|---|---|---|
| `feat:` | New feature | minor |
| `fix:` | Bug fix | patch |
| `feat!:` / `BREAKING CHANGE:` footer | Breaking change | major |
| `docs:`, `chore:`, `refactor:`, `test:`, `ci:`, `style:`, `perf:` | No user-facing change | none |
